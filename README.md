# ColorOS 后台增强

ColorOS 后台增强是一款 LSPosed 模块，用于减少系统在特定场景下过早清理、停止或冻结后台应用。

它不改变系统的全局内存兜底机制，也不会承诺所有应用在任何情况下都保持运行。具体效果会因系统版本、应用类型和当前内存压力而不同。

## 主要功能

- 基础保护：减少系统定期清理、后台进程清理和后台应用强制停止；
- 场景保护：相机、录像、游戏、AI 功能和游戏赛事模式；
- 低内存保护：控制系统在内存紧张时的集中清理；
- 应用分组清理保护：减少系统按场景批量清理后台应用；
- 后台冻结保护：减少后台冻结，并提供系统冻结支持检测；
- 运行记录和诊断：查看检测、阻止、安全放行次数以及功能加载状态。

## 安装和启用

1. 安装本模块；
2. 在 LSPosed 中启用本模块；
3. 勾选以下作用域：
   - 系统框架（android）；
   - Athena（com.oplus.athena）；
4. 重启手机；
5. 打开模块，在首页确认状态已经正常加载。

首次启用模块、修改 LSPosed 作用域或更新模块后，建议按照页面提示重启手机。

## 保护模式

首页提供三种模式：

- **均衡**：优先减少常见的后台清理，兼顾系统稳定性；
- **增强**：开启更多保护策略，可能增加内存占用和待机耗电；
- **自定义**：逐项控制高级策略。

只有选择“自定义”后，才会显示需要逐项调整的高级策略。

## 风险提示

部分设置可能减少系统的内存回收，导致内存占用或待机耗电增加；实验性设置的兼容性可能因系统版本而异。

详情页会按设置归属显示“高风险”“很高风险”和“实验性”标记。首次开启高风险设置时，应用会再次确认。

建议先使用观察模式确认行为，再决定是否开启阻止功能。

## 运行记录

首页的“运行记录”会显示：

- 已检测：系统相关行为被检测到的次数；
- 已阻止：模块实际阻止的次数；
- 安全放行：设置暂时不可用时，为避免影响系统而放行的次数。

点击运行记录卡，可以查看各项保护的详细记录。尚未触发的功能也会显示为 0 次，这不代表功能失效，只表示当前还没有检测到对应场景。

## 诊断和故障排查

如果首页提示需要重启、设置未同步或功能加载状态异常，请进入“Hook 诊断与统计”，点击“重新检测 Hook 状态”。如果问题仍然存在，请按照页面提示检查 LSPosed 作用域并重启手机。

详细的普通用户排查说明见：

```text
docs/troubleshooting.md
```

## 隐私和数据

模块不依赖云端服务。运行记录保存在本机，用于显示统计和排查问题。

只有在用户主动点击“复制诊断信息”时，应用才会生成可复制的诊断内容。分享前请先检查其中是否包含设备信息、应用包名或系统状态。
