# 使用说明

## 适用场景

本模块适合希望减少 ColorOS/OPlus 系统过早清理后台应用的用户。它主要针对相机、游戏、AI、低内存和后台冻结等场景提供可选保护。

不同系统版本可能使用不同的后台管理策略，因此某些功能可能显示为“当前系统不支持”。这是兼容性提示，不是安装失败。

## 首页说明

首页从上到下包含：

1. 模块状态：确认模块是否已经加载；
2. 启用后台保护：总开关；
3. 运行记录：查看总体检测、阻止和安全放行次数；
4. 保护模式：选择均衡、增强或自定义；
5. 基础保护：控制常见后台清理行为；
6. 高级策略：仅在自定义模式下显示；
7. 观察模式：只记录，不阻止。

运行记录卡可以直接进入详细诊断页面。

## 如何选择模式

### 均衡

适合大多数用户。它只启用较常见、影响相对可控的保护策略。

### 增强

适合希望尽量保留后台应用的用户。可能增加内存占用和待机耗电。

### 自定义

适合需要按场景调整的用户。进入对应分类后，可以独立开关各项策略。

## 观察模式

开启观察模式后，模块仍会记录检测到的系统行为，但不会阻止系统执行原本的清理或冻结操作。

建议在首次使用新策略时先开启观察模式，观察一段时间后再决定是否正式阻止。

## 运行记录中的结果

- **已阻止**：模块阻止了对应系统行为；
- **观察记录**：观察模式下检测到行为，但没有阻止；
- **未阻止**：当前设置允许系统继续执行；
- **配置不可用，已安全放行**：模块暂时无法确认设置，为避免影响系统而放行。

## 重启规则

以下情况通常需要重启手机：

- 第一次启用 LSPosed 模块；
- 修改 LSPosed 作用域；
- 更新模块安装包；
- 页面明确提示需要重启。

普通功能开关在设置同步正常时通常不需要重启。如果页面显示“设置同步”异常，请先进入诊断页重新检测；问题仍存在时再重启手机。
