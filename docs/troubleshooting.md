# 常见问题

## 首页显示“模块尚未生效”

请依次确认：

1. LSPosed 中已经启用本模块；
2. 作用域中勾选了“系统框架（android）”；
3. 作用域中勾选了“Athena（com.oplus.athena）”；
4. 手机已经完成重启。

如果刚刚安装、启用模块或修改作用域，请先完成一次正常重启，再重新打开模块。

## 首页提示需要重启

这通常表示模块或作用域的变化还没有进入系统进程。请保存当前设置并重启手机，不需要重新设置已有的作用域。

## 设置同步异常

进入“Hook 诊断与统计”，点击“重新检测 Hook 状态”。如果仍然提示同步异常：

1. 确认模块没有被系统限制运行；
2. 确认 LSPosed 作用域没有被取消；
3. 重启手机后再次检查。

设置暂时无法同步时，模块会优先安全放行，不会因为读取失败而强行改变系统行为。

## 某项功能显示“当前系统不支持”

这表示当前系统版本没有找到该功能需要的系统接口。模块不会强行启用它，也不会影响其他功能。

## 运行记录全部为 0

这通常表示当前还没有检测到对应场景，不代表模块一定异常。可以：

- 打开相机或开始录像，测试相机相关保护；
- 启动大型游戏，测试游戏相关保护；
- 在系统内存压力较高时观察低内存保护；
- 使用一段时间后再查看记录。

如果所有功能在实际场景下长期都没有任何记录，请进入诊断页重新检测，并确认模块状态已经加载。

## 为什么有“安全放行”记录

当设置暂时不可读取、模块桥接暂时不可用或系统状态无法确认时，模块会选择放行系统行为，以避免造成系统不稳定。安全放行次数不等于功能阻止失败，而是模块的保护性设计。

## 如何反馈问题

请先进入诊断页，点击“复制诊断信息”。分享前请检查内容，确认其中没有不希望公开的设备信息、应用包名或系统状态。
